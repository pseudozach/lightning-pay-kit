# Trademarks and provider names

The MIT license covers this project's source code only. Third-party product
names and marks remain the property of their owners and are used, where
present, only for truthful nominative identification. They do not imply
endorsement. This repository ships no third-party logo files; the UI uses
generated text initials so unclear image licenses cannot be accidentally
relicensed.

To request a correction or removal, follow the private contact process in
`SECURITY.md` and mark the request as a trademark or metadata issue.
